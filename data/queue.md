# 追加予定の資格キュー

週次更新時に1〜2件ずつ、一次情報を確認してから `data/exams/` に追加する。
優先度は「アフィリエイト単価 × 検索需要 × 締切事故の起きやすさ」で判断。

## 優先度: 高
- [ ] 社会保険労務士(2027年度) — 2026年度試験は8/23実施・申込終了。2027年度は例年4月上旬に官報公示・4月中旬〜5月末が申込期間の見込み(2026-08-04時点、二次情報で確認・公式未公示)。2027年4月に再確認
- [ ] 司法書士(2027年度) — 講座単価が高くアフィリエイト価値大。2026年度は申込終了。2027年度は例年4月1日に官報公告の見込み(2026-08-04時点、二次情報で確認・公式未公告)。2027年4月に再確認
- [ ] 中小企業診断士(1次・2次) — 講座単価高。2026年度1次は8/1-2実施・申込は4/23〜5/27で終了済み。2027年度は例年3〜4月頃に日本中小企業診断士協会連合会が公示予定(2026-08-04時点、公式未公示)。2027年3月に再確認

## 優先度: 中
- [ ] 登録販売者 — 都道府県ブロックごとに8〜12月実施
- [ ] ケアマネジャー(介護支援専門員) — 例年10月試験・申込は都道府県ごと6月頃。2026年度分は申込時期(6月頃)を過ぎているため2027年度分を6月頃に再確認
- [ ] 秘書検定 — 6月・11月・2月実施。2026年度第2回(11月実施)の申込受付は9/3〜開始予定。9月に再確認
- [ ] 簿記 第175回(2027年2月・2級3級のみ) — 174回(2026-11-15実施)終了後に追加

## 追加時のルール
1. 必ず公式(実施団体)サイトで日程を確認し、sources の先頭に公式URLを置く
2. 受験料は公式で確認できた場合のみ記載(不明なら null)
3. description は事実のみ。合格率などの数字は公式発表があるものだけ書く
