## デプロイ
- 前回(2026-10-26)の未pushコミット3件は origin/main(loop 記録2件)と分岐していたため、origin/main に rebase した(ファイルの重複なし)
- **未push(2週連続)**: `git push origin main` が実行環境の権限設定(Bash の push 許可なし)で拒否されたため、ローカルコミットのまま終了。前回分3件+今回分のコミットが未デプロイ。check.mjs はエラー0件のため、手動で `git push` すれば GitHub Actions でデプロイされる
- **恒久対策が必要**: launchd 実行時の権限設定(.claude/settings.json の permissions.allow)に `Bash(git push:*)` を追加しない限り、毎週未デプロイが続く
