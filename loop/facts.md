# 参照してよい事実 — maniau seo-loop

> ここに書いていないことは、断定して書かない。迷ったら書かない。
> 実行時に公式ページで確認した事実を使ったときは、出典URLを progress.md の備考に残す。

## 正データ(書いてよい事実)
| 区分 | 正データ | ルール |
|---|---|---|
| 試験日・申込期間・合格発表日 | `data/exams/<slug>.json` の `sessions` | ここにある日付だけ書ける。推測で日付を埋めない(「例年◯月頃」も具体日付にしない) |
| 受験料 | 同 `fee` | null なら書かない(サイト側で「公式サイトでご確認ください」と出る) |
| 実施団体・公式URL | 同 `organizer` / `officialUrl` / `sources` 先頭 | — |
| 受験方式 | 同 `examType`(fixed / cbt / tbd / varies)と `cbtNote` / `tbdNote` / `variesNote` / `applicationNote` | 「随時受験」「地域で異なる」等はこの値どおりに書く |
| 資格の説明 | 同 `description`、および実行時に `sources` 先頭の公式ページで確認できた内容 | 公式ページで確認できない一般論・評判は書かない |

## サイト自身について言ってよいこと
- 実施団体の公式発表をもとに、週1回(自動)で日程を確認・更新している
- 各資格ページに情報源と最終確認日(`lastVerified`)を明記している
- 申込前に必ず公式サイトで確認するよう案内している

## 禁止(書かない)
- 合格率・難易度・必要勉強時間・年収などの数値(公式発表を実行時に確認でき、出典URLを残せる場合を除く。seoTitle/seoDescription には一切書かない)
- 架空の体験談・口コミ・「当サイト利用者の声」
- 他社講座の比較・優劣の断定、アフィリエイト先の誇張表現(景表法・ステマ規制)
- 「必ず合格」「最短」「おすすめNo.1」などの断定・最上級表現
- 公式で未発表の次回日程の具体日付
